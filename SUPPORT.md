# Getting help

**Email:** info@ganado.cz · subject **Ganado Bridge support**. Support is asynchronous and best effort during the preview; no payment or call is required and no response-time guarantee is offered.

For a public, non-sensitive bug use the [bug form](https://github.com/cynarax/bridge-by-ganado/issues/new?template=bug.yml). Security problems belong in private email, subject **Bridge security report**, not a public issue.

Include the Bridge version, macOS/Node version, AI client, connection route (local or managed), exact failing step and redacted error. Reproduce with a disposable file. Never send `relay.json`, pairing codes, API tokens, private keys, customer files or unredacted logs.

Before reporting, read [INSTALL.md](INSTALL.md). A paired Mac must be awake with Bridge running; a Developer Mode connection is different from a directory listing. For an edit conflict, re-read the file. For an uncertain command result, poll the existing session before starting another command. For a failed revocation, preserve local state until it can be retried.

Data removal and historical-order questions: use the same email with **Bridge data request**, **Remove me from Bridge** or **Bridge historical order**. Do not send card data. [Privacy](https://ganado-bridge.vercel.app/privacy) · [Terms](https://ganado-bridge.vercel.app/terms).
