# Roadmap — measurable release gates

Status date: 19 September 2026. This is a sequence of work, not a release-date commitment.

## Early access

Public website, workflow guides, interest capture, privacy notice and a defined macOS-first use case.

## Next: independent activation

An independent Mac must install the agent, connect an authorized client, complete one read → checked edit → process verification task, revoke the connection and uninstall it without a founder call. This is the current priority.

## Then: private beta

A small group of relevant opt-in users, measured activation and repeat use, clear evaluation terms and redacted diagnostics. No fictitious user count or waiting-list scarcity.

## Paid release

Only after delivery and entitlement provisioning, account isolation, checkout/cancellation, final terms and a supported connection are ready. The planned individual price is €19/month; no payment is currently collected.

## Directory distribution

Prepared listing information and review scenarios do not mean submission or approval. The customer MCP connection needs a provider-supported public distribution path and an isolated reviewer account before submission.

## Update: local distribution available

The 0.1.0-preview.2 local bundle and evaluation licence are public, and archive-level first-task checks passed on a separate macOS runner. The next activation gate is the real desktop-client UI and one independent person finishing a useful task without assistance. Hosted multi-account connectivity and the OpenAI directory remain separate work.
